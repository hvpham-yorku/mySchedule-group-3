Meeting Date: 2025, 03-17

Participants: Chivuzo(Edwin) Product Owner, Aleem \- Software Developer, Samuel \- Software Developer,  Alex \- Software Developer

Sprint Goal: The main sprint goal of this sprint is to add more advanced functionality in our application, that allows users to perform more complex operations in MySchedule. This includes but may not be limited to implementing setting task reminders, creating task categories, search for tasks and lastly pinning important tasks.

Potential Issues/Spikes: Some spikes that might come up are how the user interface and the GUI components will be laid out and interact with each other, since the user stories for sprint 2 are more complex and involve more user interaction and the group needs to consider how the user will interact with one another.

Team Capacity: The total amount of hours the team is able to supply is around 25 on average per week for sprint 1 with each individual providing around 6-7 hours per person. However, the workload may fluctuate per person as needed depending on the amount of work assigned and completed given that some user stories are not needed to be fully completed but instead would be nice to start on/partially completed/fully completed as mentioned below.

Decisions around User Stories: The following user stories that must be completed this sprint based on the sprint goal are.

1) Search Tasks.  
2) Set Task Reminder.  
3) View Task Progress.  
4) Pin Important Tasks.

In addition, it would be nice if members would be able to at least start if not fully complete the following user stories but these user stories are not required to be completed or start per the discussions in the sprint meeting. 

1) Undo Task Deletion.  
2) View Completed Tasks History.  
3) Create Task Categories.   
4) Set Recurring Tasks.

Based on some discussions made during the sprint meeting, we have decided to remove two user stories from the current sprint, “Share Tasks”, and “Attach Files to Tasks”, since these two user stories go beyond the scope of the current sprint goal. For example, the “Share Tasks” user story would require implementing logic regarding user’s, finding users, and finding tasks to share, which would be better suited for our next sprint, sprint 3, which focuses on user interaction in all aspects like adding photos, files, a profile, and sharing tasks with friends

1) Share Tasks.  
2) Attach Files to Tasks.
